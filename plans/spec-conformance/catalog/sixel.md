# Sixel Graphics Catalog

DCS q sixel introducer + payload + behavioral invariants. Section 01 populated the original 5 rows; Section 12 (Sixel) expanded the catalog with per-operator rows (from the `#` / `"` / `!` / `$` / `-` / data-byte operators), behavioral rows (background modes, abort paths, palette reset, repeat clamp, pixel-buffer cap, raster-before/mid-stream, cross-stack z-order and ImageCache hand-off), and drives them all to `verified` via the spec_chain harness. See `plans/spec-conformance/audits/section-12-top-down-inventory.md` for the top-down audit that sources every row below.

Section 12 is NOT blocked by BUG-08-8 — sixel logic lives in `oriterm_core/src/term/handler/image/sixel.rs` (140 lines) and `oriterm_core/src/image/sixel/mod.rs` (436 lines), not `kitty.rs`. BUG-08-8 continues to block §13 (Kitty Graphics) whose implementation targets `kitty.rs` directly.
