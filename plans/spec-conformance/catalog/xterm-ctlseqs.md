# Xterm Control Sequences Catalog

Xterm-specific CSI extensions that are NOT ECMA-48, NOT DEC private modes, and NOT OSC. Covers window manipulation, cursor style, save/restore private mode values, modifyOtherKeys, SCP (Select Character Path), and the `CSI ? u` keyboard query that sits in the same dispatch namespace as DECSET/DECRST but is NOT a DECSET/DECRST.

Primary reference: `xterm ctlseqs.html` (Thomas Dickey's official reference).
